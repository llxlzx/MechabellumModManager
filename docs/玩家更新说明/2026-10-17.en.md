# Update of 17 October 2026

This manager release is 2.0.2. The mod catalog is updated with it. If you already have the manager installed, install the new setup over it. Your mods and settings stay.

## Manager

Every row in Installed and Workshop has Feedback, so you can send a problem with that mod to its author.

If the author left an email address, Feedback opens a message to them. If they left a web page, it opens that page. If they left any other text, the whole text is copied. If they have not left a method yet, you see: This author has not left a feedback method yet.

Most authors' contact details are not collected yet. They will be filled in over time. If you submit a mod from now on, leave a way for players to send you feedback. Both Chinese-speaking and English-speaking players need to be able to reach you with it.

Mods by 巴巴 already have a feedback method. On the China edition, Feedback opens the QQ Channel post: https://pd.qq.com/s/mrm8s2di . On the international edition, Feedback opens 巴巴's Discord profile: https://discord.com/users/592955314635014155 .

Suggestions about the manager itself still go to the manager maintainer.

The China setup uses the domestic mirror by default. The international setup uses GitHub by default. Both packages are the same program. If you already installed the manager, your existing download route is left as it is.

## Newly listed mods

**Credit Helper**

After you return to the main menu, if 48 hours have passed since the last claim and unclaimed credits remain, it claims them once. While the credit shop is open, it can buy skins, emotes, and similar items from a list and discount you set beforehand. Supports Official.

**Hide Control Tips**

Hides the camera and control hints at the bottom left of the battle screen. It takes effect as soon as it is installed, with no hotkey. Supports Official and Test.

**Upgrade Helper**

During deployment, it lists units you can upgrade, with the level and the cost of that upgrade. Left click upgrades one, right click locks that unit type, and the title can upgrade the list at once. It stops after you finish deploying. Supports Official.

**Grid Ruler**

During deployment, press C to switch between two views: a colored grid for position, and distance rings for spacing. The rings can appear throughout the deployment phase. Supports Official.

## Existing mods

**BattleSuite Standard Match HUD** is now 1.2.1. If you have 1.2.0 installed, refresh Workshop and you can update. It still shows information only while you are spectating live. You do not see the opponent's information in your own match.

## Usage

The list can group mods as Tournament-legal mods, Casual mods, and Uncategorized mods. This update places every listed mod in Uncategorized mods for now. None are placed in Tournament-legal mods or Casual mods yet. Each mod will be judged later and then moved into the matching group.
