# 钢铁指挥官 Mod 管理器 — 使用说明

## 系统要求

- Windows 10/11 **64 位**
- 已安装 [.NET 8 桌面运行时（Desktop Runtime x64）](https://dotnet.microsoft.com/download/dotnet/8.0)
- 已通过 Steam 安装 **Mechabellum（钢铁指挥官）**

首次双击若提示缺少运行时：安装上述 Desktop Runtime 后重试。

## 快速开始

1. 解压本压缩包到任意目录（无需安装）
2. 双击 `钢铁指挥官Mod管理器.exe`
3. 若未自动找到游戏：点 **设置 → 浏览…**，选择含 `Mechabellum.exe` 的游戏目录  
   （常见路径：`…\Steam\steamapps\common\Mechabellum`）
4. 若提示缺少 MelonLoader：点 **一键安装 MelonLoader**（需能访问 GitHub）
5. 导入 Mod（DLL / Zip / 文件夹）→ 勾选进方案 → **应用方案** 或 **应用并启动**

## 数据位置

默认配置与 Mod 库保存在：

`%AppData%\MechabellumModManager\`

与解压目录分离，换电脑不会带走你的库；可在设置中勾选「便携数据根」改用程序旁 `data\` 文件夹（需重启）。

## 注意

- 仅建议用于客户端 QoL Mod；修改战斗逻辑可能导致 Data Error / 处罚，风险自负
- 名称关键词会自动标「高风险」，可能误报或漏报
- 本分发包**不含**任何第三方 Mod 文件

## 版本

原版管理器（空库），不含本机调试用 Mod。
