# 钢铁指挥官 Mod 管理器 — 使用说明

## 安装（推荐）

1. 运行 `钢铁指挥官Mod管理器_Setup_v*.exe`（需管理员权限）
2. 选择管理器安装目录
3. 选择游戏路径（含 `Mechabellum.exe` 的目录；可自动探测）
4. 组件建议保持默认：
   - .NET 8 Desktop Runtime（管理器）
   - .NET 6 Desktop Runtime（MelonLoader）
   - MelonLoader（默认可取消）
5. 完成安装后启动管理器

若本机已装对应 Runtime，安装程序会自动跳过。

离线环境：把官方安装包放入制作安装包时的 `installer/redist/`（见该目录 README），重新编译 Setup。

## 系统要求

- Windows 10/11 64 位
- Steam 版 Mechabellum（钢铁指挥官）

## 使用

导入 Mod → 勾选进方案 →「应用方案」或「应用并启动」。

数据默认在 `%AppData%\MechabellumModManager\`（空库，不含第三方 Mod）。

## MelonLoader

请在**安装包**中勾选安装。管理器内不再提供一键安装。  
缺少 Loader 时请重新运行 Setup 并勾选 MelonLoader，或手动安装。

## 风险

仅建议 QoL Mod；修改战斗逻辑可能导致 Data Error / 处罚，风险自负。
