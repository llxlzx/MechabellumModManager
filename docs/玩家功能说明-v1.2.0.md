# 钢铁指挥官 Mod 管理器是做什么的

这是给 Steam 版《钢铁指挥官 / Mechabellum》用的 **Mod 管理工具**（当前最新：**v1.2.0**）。

它主要帮你：

1. **装好 MelonLoader** —— 游戏能加载 Mod 的基础  
2. **浏览、下载、更新社区 Mod / 插件** —— 国内一般走镜像，少翻墙  
3. **用「方案」勾选要用的 Mod** —— 一键同步到游戏，并可直接启动  
4. **可选：正式服 / 测试服双目录切换** —— 两套游戏目录分开玩  

下载：https://github.com/llxlzx/MechabellumModManager/releases/latest  

注意：只建议用界面 / 便利类 Mod；改战斗相关内容风险自负。与游戏官方无关。
