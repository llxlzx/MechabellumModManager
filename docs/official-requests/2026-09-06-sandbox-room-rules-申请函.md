# 给官方的小建议：自定义房「沙盒空架子」，内容我们社区自己填

发个玩家向的功能建议，说人话版～

## 我想要啥

自定义房希望能更自由：改每回合补给/上限、禁单位或某项科技，以及以后各种房间向玩法。  
这些**具体内容**希望主要由社区 / 外部 Mod 来做；官方尽量只提供一个能挂载的空框架。

硬前提：**正版、走官方创建房间**，不搞私服，**不影响排位 / 匹配分 / 战力**那些正式数据。

## 我希望官方怎么做（最省事版）

请官方尽量少写具体规则，只给空架子就行：

1. **沙盒房开关**  
   开房时勾选「沙盒 / 娱乐自定义（不计分）」→ 不算匹配分、不影响战力结算。

2. **只同步、不解释的规则包通道**  
   房间里能带一份有大小限制的自定义规则数据（小 JSON / 键值包都行）。  
   开房时提交，**服务器原样同步给房内所有人，不必解读里面是什么玩法**。  
   禁哪个单位、补给怎么改等，全部由双方安装的**同一套社区 Mod**按这份数据在本地执行。

3. **沙盒房放宽战报校验**  
   沙盒房不做排位那套严格战报校验（或明显放宽），避免社区一改补给/科技就 Data Error。  
   正式匹配 / 普通自定义房保持现状，不动。

我们社区负责：规则内容、界面、预设、双方 Mod 版本约定和说明。  
官方就三件事：沙盒不计分、规则包能进房同步、沙盒房战报别按排位死磕。

## 为啥这样对官方最轻

- 不用维护规则内容表，也不用实现「禁单位 / 改补给」等具体逻辑  
- 还是你们的房间系统，只是多一个不计分挂载点，不是私服  
- 不想开就关沙盒开关，或限制数据包大小，随时可控  

有开发/策划看到的话麻烦看看可不可行，谢谢！

（玩家 / 社区工具向，非官方）
