# 星辰之子 · 分层浪漫版 设计

日期：2026-10-11 · 工作目录：`demos/outer-wilds-real-pptx/`（不碰 `demos/outer-wilds-cinematic-pptx/`）
前置：9 张底图已定稿（`plates/*.png`，见 `tools/build_plates.py`）；v1 平铺版已交付（`out/星辰之子-学习教学.pptx`），用户评价"勉强凑活"。

## 1. 目标

把"一页一张图 + 一行字幕"改成**每页由多层素材按音乐逐层组装出来**，每页的页内动画和切换都有各自的浪漫意象。

验收口径（用户原话归纳）：
- 每页先出主体背景，再让主体、细节、文字以合适、平滑、浪漫的方式依次登场——不能整张图直接显示。
- 一页里套多个小动画（参考芙莉莲动态版的语法，不复刻其资产）。
- 文案不像字幕：海报式关键字 + 诺曼螺旋文字"翻译"展开。
- 每页切换各不相同，且有浪漫表达。

不变的约束：9 页、总长 78.3 s、Main Title 配乐跨页播放；五句文案逐字不改；只用游戏画面（社区截图 / 预告片帧 / 官方素材）+ 轻度 AI 修图；个人学习用途；不提交 git；不动另一会话的文件夹。

## 2. 每页的层结构（自下而上）

| 层 | 内容 | 实现 | 可在 PPT 里改？ |
|---|---|---|---|
| L0 活背景 | 主体被抹掉、补全后的背景 + 环境动态（星点呼吸、星云流动、光脉动、粒子、雾）+ 结尾的转场配合光效 | Python 渲染 1920×1080 mp4，长度 = 该页时长，不循环 | 否（改需重渲） |
| L1 主体素材 | 抠出的透明 PNG：空间站、居民、木屋、篝火等，每页 1–4 个 | PPT 原生图片 + 原生动画（淡入、缩放、路径、旋转、擦除组合） | 是 |
| L2 点缀素材 | 光点、光环、火星、碎片、闪光等小 PNG 精灵 | PPT 原生动画，按节拍出场 | 是 |
| L3 诺曼螺旋文字 | 程序生成的蓝色发光螺旋符号 PNG | 原生旋转展开 → 溶解 | 是 |
| L4 中文排版 | 关键字（铁/锌/铜/钴/好奇/星河大海/星辰的孩子）做成发光大字 PNG；整句为原生文本，按词组分段出现 | 原生动画 | 整句可改；大字需重渲 |

关键字渲染成 PNG：保证换电脑放映时字形和光晕不变。整句保留为文本，便于修改，字体沿用现有优先级（思源宋体 → 宋体），装饰英文用 Garamond / Perpetua Titling。

## 3. 分镜（时间为该页内相对秒数；出场点按配乐乐句微调，乐句级对齐，不做毫秒卡点）

全片起点：p1 0 s · p2 7 · p3 17 · p4 27 · p5 36 · p6 44 · p7 53 · p8 63 · p9 72 · 终 78.3。

### p1 冷开场 · 第一缕光（7 s）
- L0：纯黑 → 星星逐颗亮起（0–2.5）。
- 2.0 核心光点在中心亮起并晕开（L2 光晕，缩放 0.2→1 + 淡入）。
- 2.8–5.0 空间站由核心向外显现：L1 空间站 PNG 以"轮子/圆形"擦除从中心展开，同时 0.88→1.0 放大、旋转 6°，缓入缓出。
- 4.0 十字光芒展开（L2 四道光线精灵，缩放拉伸）。
- 4.6–6.4 STARDUST 逐字母点亮：每个字母上方落下一粒光点（L2 路径 + 淡出），字母随即淡入。
- 6.4 核心骤亮，L0 白光吞没 → 切换"闪光"。

### p2 铁 · 烟花般的盛放（10 s）
- 0–1 星空。1.0–3.0 雪地（L1）从下方升起 12% 高度，缓停。
- 3.0 地平线上蓝色小星（L1 超新星 PNG，缩放 0.08）出现，3.0–5.5 膨胀至 1.0 并伴随 L0 光爆。
- 4.5–10 L0 蓝色粒子如花瓣飘落。
- 5.8 光环（L2）荡开；6.0 "铁"大字从光环中心浮现（缩放 1.3→1.0 + 淡入）。
- 6.8–9.0 螺旋文字展开 → 溶解，整句分 2 段擦除出现。
- 结尾 → "涟漪"。

### p3 锌 · 两颗星的相拥（10 s）
- 0–1 深空。1.0–4.0 两个光点（L2）沿双螺旋路径互绕，越转越近。
- 4.0 相拥闪光（L2 闪光精灵 + L0 光爆）。
- 4.2–7.0 星尘团（L1）从 0.1 旋转扩散至 1.0。
- 6.5–9.0 螺旋文字展开 → "锌"大字 → 整句分 2 段。
- 结尾 → "旋涡"。

### p4 铜 · 目送（9 s）
- 0–2 L0：天空 + 正在爆发的太阳，光像心跳般明暗、越来越慢。
- 1.5–3.5 森林与村庄剪影（L1 中景）从暗处渐显（亮度 0→1）。
- 3.0–5.0 居民（L1 前景）自左缘缓缓入画 8%，停住。
- 4.0–9 碎片如雪飘落（L0）。
- 5.5 "铜"从爆发光中浮现；6.3–8.0 整句分段。
- 结尾 → "微光"（不可用时降级为"溶解"）。

### p5 钴 · 来自远方的信（8 s）
- 0–1.5 暗星空，星点闪烁。1.0–3.0 星云颜色一团团晕染（L0）。
- 2.5 光球亮起（L2 光晕）。2.8–4.5 持杖人剪影（L1）自下方升入 6%。
- 4.5 "钴"从远处小点飞近（缩放 0.05→1.0 + 淡入）；5.2–7.0 整句。
- 结尾 → "飞过"。

### p6 好奇 · 火星化作星星（9 s）
- 0–1.5 夜空 + 绿色星球（L0）。1.0–3.0 金色月亮（L1）从树后升起。
- 2.5–4.5 树与木屋（L1）从剪影显形；窗灯（L2）逐扇亮起。
- 4.0 篝火（L1）点燃；4.0–9 火星飘起并在高处化为星星（L0）。
- 5.2–7.5 整句分 2 段，"好奇"二字被火光照亮放大。
- 结尾 → "闪耀"。

### p7 渴望 · 对流星许愿（10 s）
- 0–1.5 银河（L0）。1.0–3.0 山丘与树林剪影（L1）升起。
- 2.8 塔下小屋窗灯亮起（L2）。
- 3.0–10 流星由稀到密（L0，沿用 60 颗 + 轮廓遮罩）。
- 5.0 一颗流星拖尾划过，"星河大海"沿其轨迹擦除写出；整句其余部分随后。
- 结尾 → "缩放"（坠入光中）。

### p8 星辰之子 · 我们本就是星光（9 s）
- 0–0.8 黑。0.8–3.5 太阳（L1）自左侧推入，表面翻涌（L0）。
- 2.5–4.5 前景星球与建筑剪影（L1）漂入。
- 4.5–7.0 金色光尘（L2 精灵群，路径汇聚）从太阳飘向中央，聚成"星辰的孩子"大字；整句前半先出。
- 结尾 → "淡出到黑"（约 2.5 s）。

### p9 余烬 · 晚安（6.3 s）
- 0–2 小星球（L1）从一个光点显现（缩放 0.05→1 + 淡入）。
- 1.5–4 篝火闪动，星星一颗颗熄灭（L0）。
- 3.3–6.3 小星球缓缓漂远并淡出；全片结束。

### 开场与切换汇总
p1 入场：慢速自黑淡入。1→2 闪光；2→3 涟漪；3→4 旋涡；4→5 微光；5→6 飞过；6→7 闪耀；7→8 缩放；8→9 淡出到黑。每个切换都在 L0 结尾烘焙配合光效。COM 不支持的切换按最近似效果降级，并在交付报告中逐条列出。

### 文字规则（样片评审后新增，所有页适用）
- **位置避开高光**：文字只放在该页背景全程都暗的区域（含结尾光效、脉动、粒子最亮的时刻）。构建前 `deck/legibility.py` 用文字可见期间的背景视频逐像素峰值亮度 + 同时可见的非文字层，计算文字框的 90 分位亮度，超过 0.45 即拒绝构建。
- **结尾光效不铺满全屏**：页内结尾闪光只在主体附近绽放（`Flash(fill=False)`），整屏白交给下一页的切换效果。
- **文案四层出场**（`build_layered.text_layers`）：暗色柔边衬底先淡入（提前 0.35 s）→ 暖金光晕放大绽放 → 字体（方正姚体）自左向右擦出 → 一颗光点沿字行"书写"后淡出。
- **关键字**：诺曼螺旋先在暗处展开，关键字从螺旋中心浮现（"翻译"），二者同位。
- **英文字母**：实心星光字母 + 独立光晕层，由主体光源飞出的火花逐个点亮。

## 4. 制作流程（单元划分）

| 单元 | 职责 | 输入 → 输出 |
|---|---|---|
| `tools/split_layers.py` | 按每页配方抠主体：太空类用亮度/色彩阈值；复杂场景用 rembg（U²-Net）或手绘多边形蒙版；输出透明 PNG 与主体蒙版 | 源图 → `layers/<page>/<element>.png` |
| AI 补背景（手动步骤） | GenerateImage 以源图为参考、提示"抹掉主体、保留构图与游戏画风" | 源图 → `layers/<page>/bg_clean.jpg` |
| `tools/living_bg.py` | 背景动态：星点呼吸、星云流动（低频位移场）、光脉动、粒子（花瓣/雪/火星）、结尾转场光效；复用流星模块 | `bg_clean` + 配方 → `fx/bg_<page>.mp4` |
| `tools/glyphs.py` | 诺曼螺旋文字与发光关键字 PNG | 文案 → `layers/type/*.png` |
| `deck/storyboard.py` | 纯数据：每页元素列表、出场时间、动画类型与参数、切换（第 3 节的结构化版本） | → dict，可单测 |
| `build_deck.py`（改） | 按 storyboard 用 COM 组装：背景视频、元素、精灵、文字、原生动画、切换 | → `out/星辰之子-分层浪漫版.pptx` |
| `verify_deck.py`（改） | 校验每页层数、动画数、切换类型、时长总和、媒体挂载；导出关键时刻截帧 | pptx → 报告 + 预览 |

`storyboard.py` 是唯一的分镜来源；构建器不写死时间。

## 5. 样片关口

先只做 **p1 与 p4**（太空 / 复杂地面，难度最有代表性），生成两页的 pptx 子集 + 每页 3 个时刻的截帧 + 一段屏幕录制（PowerPoint 导出 mp4），用户确认后再铺开其余 7 页。

## 6. 验证

- 单测：storyboard 时间不越界、每页至少 3 个分层出场、切换互不重复、总长 78.3 s；抠图蒙版覆盖率；背景视频帧数 = 时长 × 24。
- 结构校验：重新打开 pptx 逐页检查。
- 视觉校验：用 PowerPoint 把成片导出为 mp4，抽帧检查出场顺序和边缘瑕疵。

## 7. 风险与降级

- 抠图边缘 / AI 补背景瑕疵 → 边缘羽化 + 主体轻微外发光遮缝；不行则该元素改为"整图分区擦除显现"。
- COM 不支持的切换或动画参数 → 最近似替代，交付时列出。
- 文件体积：9 段 1080p 背景视频预计 60–120 MB；超出时降码率到 8 Mbps。
- 放映机器性能：视频 + 多层动画在低配电脑上可能掉帧，交付时附 PowerPoint 导出的 mp4 成片作兜底。

## 8. 不做

毫秒级卡点；AE 级实时特效；同人图；改五句文案；碰另一会话的文件夹。
