# 信号站 SIGNAL · 星空跟轨 PPT 能力预览（真实 .pptx）

日期：2026-10-11  
状态：设计对话已批准，待用户审阅本 spec 后进入实现计划  
范围：Mode A 能力预览模版；非竞聘正稿；非 Mod 管理器主程序

## 1. 目标

用**真实 PowerPoint `.pptx`** 交付一套可放映的「星空 / 夜航 / 暖信号」短片感预览模版，题材自拟为 **信号站 SIGNAL**，并按用户本地音轨 **Travelers' encore**（Andrew Prahlow）的结构做**自动换片跟轨**，证明在 `.pptx` 约束下动画与版式能达到的上限。

成功标准（放映）：

1. 本机幻灯片放映时音频与 16 页自动换片大致贴合结构点（尤其 ~1:00 抬升与 ~2:04 高潮）。  
2. 前三页有星空短片感；第 11 页有可感知的 iris/圆形高潮。  
3. 全片无参考游戏标识、封面构图、可辨认 IP 造型；占位文案即可。  
4. 仓库不包含 mp3；构建脚本从用户本机路径复制到 gitignore 的 `media/`。

## 2. 非目标

- 网页伪 PPT（已有 `demos/bocchi-ppt-demo/`，本任务不改它）  
- 竞聘正稿文案与版式  
- 修改 Mod 管理器应用代码  
- 将原曲随仓库分发或宣称可再分发该音轨  
- 追平参考影视 PPT 包的上千动画节点密度  
- 精确到每个拨弦/鼓点的毫秒级卡点（以结构点 + ~91 BPM 拍网为准）

## 3. 约束与版权

- 遵循 `2026-10-11-ai-ppt-production-guide.md`：学语法、不抄 IP；视觉派生自「星空旅人」气质，**不是** Outer Wilds 皮肤复刻。  
- 音源仅用于用户本机预览构建：  
  - 默认源路径：`d:\KuGou\Andrew Prahlow - Travelers' encore.mp3`  
  - 实测时长：**229.5s**；估算拍感约 **91 BPM**（周期 ~0.66s）  
  - `media/*.mp3` 必须在 `.gitignore` 中  
- 交付说明须写明：成品含用户自备音轨时仅供个人放映预览，版权归权利方。

## 4. 音轨结构（构建用 cue）

能量轮廓（4s 窗 RMS，用于入点，非公开扒带文档）：

| 区段 | 大致时间 | 制作用意 |
|------|----------|----------|
| 疏远铺底 | 0–60s | 冷开场、慢标题 |
| 第一次抬升 | ~60s | 章节「校准」 |
| 再抬 | ~84–104s | 概念页加密 |
| 主高原 | ~104–170s | 叠字 → iris → 余韵 |
| 回落 | ~172s+ | settle / 疏句 |
| 近尾 | ~208s+ | End Lock |

页内 stagger 优先使用 **0.33s / 0.66s** 拍网。

## 6. 视觉系统

- **场：** `#070B14` 微蓝黑渐变 + vignette  
- **星点：** 低密度冷白小点 + 极少暖点；禁止满屏星空位图墙纸  
- **信号核：** `#E8B45A`（唯一强情绪色）  
- **辅冷：** `#7EB0C8`（航迹 / 幽灵英文，面积克制）  
- **字色：** `#F2F4F7`；幽灵英文低对比  
- **字体：** 中文系统粗黑栈；英文窄距大写  
- **图层：** 场 → 星/航迹 → 暖核 → vignette → 字 → 角标页码  
- **物理：** ease-out；无弹跳；scale ≤105%；仅第 11 页 iris

## 7. 架构与交付物

目录：`demos/signal-station-pptx/`

| 文件 | 职责 |
|------|------|
| `timing.json` | 入点、hold、角色、文案、动效档的单一真相 |
| `build_deck.py` | 空文件 16:9 静态孪生 + OOXML 动画/换片/音频挂载 |
| `media/` | 构建复制的 mp3（gitignore） |
| `out/信号站-SIGNAL-preview.pptx` | 放映成品（可 gitignore 大文件；以 README 为准） |
| `README.md` | 构建命令、放映步骤、版权说明 |
| `.gitignore`（目录内或根配置） | 忽略 `media/*.mp3`；可选忽略 `out/*.pptx` |

实现路径（已定方案 1）：

1. 静态优先：每页先作为海报可读。  
2. 关键页注入：碎字标题、章节锤、第 11 页 iris 近似、Proof Trio stagger。  
3. 幻灯片切换时间 = hold；音频自第 1 页跨幻灯片播放至结束。

## 8. 测试与验收

- 构建：源 mp3 存在时 `python build_deck.py` 成功写出 pptx。  
- 源 mp3 缺失时：清晰报错并提示路径，不写入损坏文件。  
- 人工：PowerPoint / WPS 打开 → 幻灯片放映 → 听完整曲，核对第 6/11 页是否落在抬升与高潮附近。  
- 自检：无 IP 字符串；`media/` 未被 git 跟踪。
