# 孤独摇滚气质 · PPT 动画能力试水版（网页）

日期：2026-10-10  
状态：设计已口头批准，待用户审阅本 spec 后实现  
范围：能力演示；非招生志愿者协会竞聘正稿

## 目标

用单页网页做出接近「类 PPT 动画短片」的观感上限试水，气质对齐《孤独摇滚！》的乐队感、色块与卡点节奏，供用户确认再决定竞聘正稿路线。

## 非目标

- 导出真实 `.pptx`、配乐、录片上传
- 使用官方立绘、剧照、原曲或可辨认角色造型
- 撰写竞聘正文（后续单独进行）
- 改动 Mod 管理器主程序逻辑

## 交付物

目录：`demos/bocchi-ppt-demo/`

| 文件 | 职责 |
|------|------|
| `index.html` | 结构、7 屏容器、控件 |
| `styles.css` | 配色、噪点、转场、字效 |
| `app.js` | 分镜状态机、自动播、键盘/点击 |
| `README.md` | 如何本地打开与快捷键 |

打开方式：本地静态服务器或直接打开 `index.html`（以 README 为准）。

## 分镜（7 屏）

| 索引 | 名称 | 作用 | 动效 |
|------|------|------|------|
| 0 | 起势 | 黑场 | 细噪点 + 色条横扫（调音感） |
| 1 | 标题 | 主标题 | 粉/青错位叠影，微抖后稳住 |
| 2 | 四格 | 成员气质抽象 | 粉/黄/青/紫色块依次弹入 + 短标签 |
| 3 | 金句 | 歌词式文案 | 逐行划入；底栏波形进度 |
| 4 | 演出 | 高潮 | 圆形遮罩放大 → 高对比色爆炸 |
| 5 | 内容卡 | 证明可承载信息 | 3 点要点卡片侧滑（仿汇报页） |
| 6 | 收束 | 定帧 | 字标 +「Demo / 能力试水」 |

自动播总时长约 45–60 秒；支持手动翻页。

## 视觉系统

- 底：`#0E0E10` + 全局 3–5% 噪点
- 强调：`#FF4FA3` / `#3DE0FF` / `#FFE566`；辅 `#B8A0FF`；字 `#F5F5F7`
- 字体：中文粗黑（YaHei / PingFang SC 等系统栈）；英文窄无衬线点缀
- 动效：短促带过冲；硬切与圆形遮罩为主；尊重 `prefers-reduced-motion`（降级淡入）

## 交互

- 自动播放；空格 / 点击 / ← → 翻页
- 右下角：屏号、播放/暂停；`F` 全屏（若浏览器允许）

## 验收标准

1. 全屏时前 3 屏有短片感，而非普通网页翻页  
2. 第 4 屏遮罩爆炸有明显冲击  
3. 第 5 屏仍可读，证明动画风可落到内容结构  
4. 无外部图片依赖，离线可播  

## 与后续竞聘稿的关系

本 demo 只验证「动画上限」。竞聘正稿（招生志愿者协会 · 设计宣传部部长，8–10 分钟）将另定更克制的汇报视觉与文案结构；不要求正稿复用本 demo 的高对比乐队风。
