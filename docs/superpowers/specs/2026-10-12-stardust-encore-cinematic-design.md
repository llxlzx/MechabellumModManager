# 星辰之子 · 旅者安可版 —— 电影级动画重做（设计）

日期：2026-10-12　状态：用户已逐段批准（架构 / 逐页设计 / 转场 / 大字处理）

## 目标

在 `星辰之子-旅者安可版-高清` 的基础上，让整套 PPT 看起来像真正的动画：画面内部在动、镜头在动、页与页之间无缝衔接；
每页另加符合该页情绪与色彩的辅助特效；重做「好奇 / 星河大海 / 星辰的孩子」三处大字。

用户选择：做法 A（电影级混合）、电影感运动风格、转场全部重做、大字「融进场景」。

## 不变的约束

- 文案逐字不变；17 页结构、页序、每页内容起点（音乐网格 `STARTS`）不变，总长对齐 229.5 s 的 Travelers' Encore。
- 只用游戏画面（已有静帧与抠图），不引入 NASA/ESA 照片或同人图。
- 不做 git 提交；不改 `demos/outer-wilds-cinematic-pptx`、Mod 管理器代码、`demos/bocchi-ppt-demo`；不提交 `media/*.mp3`。
- 保留现有输出（v1、旅者安可版、旅者安可版-高清），新输出为 `out/星辰之子-旅者安可版-动画版.pptx/.mp4`，1080p。

## 架构

### 1. 每页一个镜头：背景视频（`tools/shot.py` 渲染，规格在 `deck/shots.py`）

- **场景**：若干景深平面（`Plane`，RGBA，深度 0=最远 … 1=最近）+ 场景内运动物体（`Sprite`，带关键帧位移/缩放/旋转/透明度）。
  平面来源：已有 v1 抠图优先（雪地、超新星、空间站、村民、人影、光球、太阳、建筑、星球、地面等）；
  其余用 Depth Anything V2 估景深后切片，被遮挡处补画（`tools/depth_layers.py`）。
- **镜头**：关键帧（时间、推进倍数、横/纵移、旋转），缓入缓出；每个平面按深度获得不同的推进与位移（视差）。
  校验：任何时刻每个平面都覆盖整个画面（不露边）。
- **画面内特效**（GPU，torch）：火焰扭动与闪烁、热浪折射、漩涡旋转、流动（云/星云/日面翻涌）、丁达尔光线、泛光、镜头光晕、
  带景深的粒子（近大远小、近处虚化）、星星闪烁/亮起/熄灭、流星、闪电、心跳光、爆发光环、色调关键帧、暗角。
- **场景内运动**：飞船升空、太阳下沉、行星公转、两颗星螺旋相撞、超新星膨胀等都在视频里完成（镜头在动，放在 PPT 图层会对不上）。
- 视频时长 = 该页时长 − `BG_TAIL`；整片第一页从黑场淡入，最后一页淡出到黑场。

### 2. PPT 图层：只放贴在屏幕上的东西

- 文案文字（沿用光效写字），挪麦螺旋翻译的单字元素（铁 / 锌 / 铜 / 钴）。
- 每页量身定制的辅助特效（见逐页设计）。凡是跟场景某一点对位的特效，用 `deck/shots.py` 的
  `screen_point(page, 场景点, 深度, t)` 按镜头算出当时的屏幕位置。
- 去掉以前与场景重复的图层（空间站、雪地、地面、人影、太阳、建筑等改由视频承担）以及过渡页的静止图层。

### 3. 转场：桥接镜头（`tools/bridges.py`）

- PPT 转场全部改为 `Cut`（时长 0），转场时间不再从上一页扣除：每页时长 = 音乐网格间距。
- 第 N 页视频最后 1.5–2.5 s 渲染成通往第 N+1 页第一帧的桥接；第 N+1 页在负时间预渲染（镜头静止、特效照常）。
  桥接结束帧必须与第 N+1 页第一帧一致（自动校验像素差）。桥接前第 N 页的 PPT 图层全部退场。
- 桥接两侧镜头缓停/缓起，掩盖切换瞬间的定格。
- 桥接样式：光源接光源（泛白收拢）、叠化、擦过（云/风沙，带噪声边）、旋转接旋转（旋涡+径向模糊）、穿黑、闪光、
  垂直摇镜衔接、流星光晕揭开。

## 逐页设计（镜头 / 画面内 / PPT 辅助特效）

1. **第一缕光**：深空缓推空间站约 25% 并向右环绕 / 星星由远到近亮起，核心点亮，光沿结构流出，舱体边缘反光 /
   核心点燃时十字星芒与光环，字母点亮时流光扫过，镜头前虚化星尘。
2. **营火醒来**：高处俯视篝火，下降推近约 20% / 火苗扭动、热浪折射、火光闪烁照亮四周、火星成串升起、余烬明灭 /
   前景虚化大火星飘过、棉花糖尖闪光、暖色暗角随火光呼吸。
3. **出发**：从天空下摇到天文台，近树快远崖慢 / 树叶摇动、云流动、山脊后丁达尔光线、远处火箭升空拖尾 /
   扫过阳光时的镜头光晕、花粉光点、火箭尾迹尖端闪光。
4. **烟花般的盛放（铁）**：雪地低角度缓慢抬头，推进约 15% / 超新星从亮点膨胀、冲击波扩散、蓝光照亮雪地、远近雪花 /
   爆发闪白、冲击光环、碎光飞散、「铁」出现时雪花光点汇聚。
5. **太阳系全景**：绕太阳环绕横移并推进 / 日面翻涌、日冕流动、行星公转、太阳风粒子 /
   轨道线依次画出、光点沿轨道跑动、行星掠过日面时镜头光晕。
6. **两颗星的相拥（锌）**：跟着双星螺旋靠近，缓慢旋转并推进 / 互绕加速、螺旋光带、碰撞强光、物质喷散 /
   碰撞闪白、两圈光环、十字星芒、金色碎屑飘落、「锌」周围光尘环绕。
7. **巨人之海**：从左向右横移跟拍，轻微手持晃动 / 龙卷风旋转上卷、云流、横飘雨雾、飞船点火升空与扬尘、远处闪电 /
   闪电时画面亮一下、前景斜雨丝、引擎光晕。
8. **目送（铜）**：村庄中缓推并微微上仰 / 铜色光团绽放照亮树林与小屋、灯笼摇晃、萤火虫、树叶微动 /
   铜色光点洒落、「铜」光晕呼吸、文字暖光掠过。
9. **挪麦雕像**：雕像脚下仰拍并环绕，雕像与天空视差 / 光柱能量上流、底部脉动、红沙被风卷起、远处星球发光 /
   每次脉动沿地面扩散光环、紫色光点沿光柱上升。
10. **来自远方的信（钴）**：从人影背后缓推向星云约 20% / 星云气体流动变色、光球呼吸、星星闪烁 /
    光球周期光波、偶尔流星、「钴」出现时蓝色光尘从光球飞向文字。
11. **太阳的余晖**：缓推并下移跟着太阳 / 太阳沉入建筑后、暖转深蓝、星星逐个亮起、窗灯亮起、信号灯闪烁 /
    146 s 地平线闪光（光环 + 十字星芒），之后温暖光斑缓慢掠过。
12. **火星化作星星（好奇）**：从月亮下摇到树屋与篝火 / 月光、火星升空化作星星、窗光跳动、树叶轻摇 /
    火星沿曲线上天点亮成星、「好奇」由火星聚成（见大字）。
13. **黑洞之口**：向洞口推进并持续旋转 / 漩涡越近中心越快、吸积光带流动、碎石被吸入、光线扭曲 /
    洞口光环、碎光被拉成细线飞向中心。
14. **对流星许愿（星河大海）**：从树林仰拍到星空并推进 / 流星雨成波、银河流动、塔灯闪烁、萤火虫 /
    最亮流星的光晕拖尾、「星河大海」由星星连成（见大字）。
15. **我们本就是星光（星辰的孩子）**：横移，建筑剪影与太阳视差明显，同时推进 / 日面翻涌、日珥、建筑光边、热浪 /
    光尘环绕文字（更丰富）、太阳边缘光晕、金色流光、「星辰的孩子」由太阳光尘聚成（见大字）。
16. **宇宙之眼**：向核心推进约 30%，越推越快 / 核心心跳、蓝色光尘旋入、光柱流动 / 每次心跳光环扩散，最后一拍泛白接下一页。
17. **余烬·晚安**：缓慢拉远、越来越暗 / 余烬渐暗、星星逐个熄灭只剩一颗 / STARDUST 消散成光尘、最后一颗星闪一下熄灭。

## 文字

- **修重影**：取消多字词的放大「呼吸」副本；所有大字的光晕与字身严格同心对齐。
- **统一字体与光效**：三处大字改用与文案相同的字体（方正姚体）和同一套光效（字身 + 暖色光晕 + 写字流光），字号比现在小。
- **大字融进场景**（摆在构图留白处，跟场景光源同色）：
  - 「好奇」：篝火飞出的火星沿曲线飞入字形采样点，聚齐后字身淡入、火星退场。
  - 「星河大海」：一颗流星划过时，字形采样点上的星星依次亮起，随后字身沿笔画方向擦入，像星座连成的字。
  - 「星辰的孩子」：从太阳飘出的金色光尘缓慢聚成字。
- 单字元素（铁 / 锌 / 铜 / 钴）保留挪麦螺旋翻译，仅修正重影。

## 验收

- 测试全部通过（新增：镜头覆盖不露边、视差顺序、负时间预渲染、特效确定性、桥接终帧 = 下一页首帧、规格时长、大字采样点、
  转场为 Cut、图层不越界）。
- **运动幅度**：成片每页平均光流（480p）明显高于高清版，每页都不低于设定下限。
- **衔接**：每处桥接终帧与下一页首帧平均像素差 < 2/255。
- 文字背后亮度门（90 分位 ≤ 0.45）照旧；音画同步无累积漂移，成片总长与音乐相差 < 1 s。
- 每页抽帧与每处转场抽帧自检，交付时展示给用户。
