## 1. 目标

做一套可在 PowerPoint 里放映的**电影感短诗式**学习 PPT：约 78 s 一气呵成，观感接近芙莉莲示范的完成度，以《Outer Wilds / 宇宙拓荒》的星辰大海气质承载「我们本是星辰的孩子」这一组金句。

成功标准（放映，对人）：

1. 全片放映一遍，整体像「有画面的短片」，而不是旧 M0 那种大字 + 稀星点。  
2. **任意一页**抽查都有打磨过的主视觉；全片看不到色块凑天体 / 假流星闪烁等粗制滥造。  
3. 至少一处**真拖尾流星雨**划过天空（序列帧或短视频叠层，多轨迹、错峰、有尾迹）。  
4. 用户的**星辰之子五句**逐句入片、一句一景，无其他叙事文案。  
5. 可自动换页放映，并挂上用户已购 OST 的 **Main Title**（见 §3.1）；构建时从本机 OST 目录复制到 gitignore 的 `media/`，**不把 mp3 提交进仓库**。

## 4. 全局工艺法（硬规则 · 每一页）

下列任一出现即视为不合格，不论该页主题是否为「星空」：

- 色块星点、圆形色块冒充行星 / 流星 / 信号  
- 大字贴在几乎空白的纯色或重复无趣底上  
- 无拖尾、无轨迹的「闪一下」冒充华丽动效  
- 未打磨的整页生截图当成品主视觉  

要求：每页具备打磨主视觉 + 可读文案层次（可含半透明英文衬字）+ 与页意匹配的连续运动（拖尾 / 光尘 / 短视频循环等）。

## 5. 叙事骨架（9 页 · 78.3 s · 一句一景）

**文案仅限下列五句（逐字使用，不增不改）：**

1. 「我们身体里的铁，来自璀璨的超新星爆炸」  
2. 「我们血液里的锌，源自两次中子星对撞后喷射向宇宙的尘埃」  
3. 「我们那微量的铜，更是需要见证一颗白矮星的死亡，即使是最微不足道的钴，也源自几十亿光年外的星云」  
4. 「某种意义上讲，人类对星空怀有好奇，是正常的。」  
5. 「渴望见证星河大海的极限，因为我们本就是 星辰的孩子。」

### 5.1 浪漫视觉语言（每页提示词的共同骨架）

每页 AI 打磨提示词必须包含以下四层，并在页表意象上具体化：

| 层 | 内容 | 要求 |
|----|------|------|
| 空间 | 深空青紫（`#0B1530`→`#3B2A6B`）为底，营火暖橙（`#E8B45A`/`#FF9A3C`）只作一处焦点 | 冷暖对比，暖色永远只占画面 ≤ 1/4 |
| 光 | 柔和体积光、星云雾霭、细碎星尘颗粒、轻微胶片颗粒 | 禁止硬边霓虹、禁止塑料感高光 |
| 运动感 | 画面本身要有「正在发生」的方向：喷射、飘散、划过、呼吸 | 便于后续动效顺势而动 |
| 留白 | 下三分之一或一侧保留低对比暗区给中文金句 | 文字永远可读（≥ 18 pt 等效） |

**叙事气质关键词（每条提示词必带 3–5 个）：** 宇宙拓荒式手绘感宇宙、星辰大海的浪漫、温柔而浩瀚、旅人与营火、光年之外的乡愁、安静的敬畏、呼吸般的节奏。

**禁用词：** UI、HUD、水印、logo、文字、低多边形、卡通贴纸、平涂色块、霓虹赛博。

### 5.2 动效语言（与 §6.3 配合）

- 冷开场：星尘由一点扩散（缓慢、单向）。  
- 句 1–3：元素层「向外喷射 / 旋进 / 环抱」的缓慢位移 + 光晕呼吸；文字逐句浮现、字距微收。  
- 句 4：营火暖光缓慢脉动，星空微微旋转（极慢），文字如低语浮出。  
- 句 5 上半：真拖尾流星雨自右上向左下成群划过，错峰 8+ 条；文字在流星停歇的一瞬落定。  
- 句 5 下半：掌心余烬与远处星云同步呼吸，一次呼吸即是一次转场。  
- 尾声：全部缓慢暗下，只留一粒光与一颗星。

视觉气质：营火暖橙 + 深空青紫 + 星尘冷白；每页一主视觉，禁止空版重复。

## 6. 素材与动效管线

### 6.1 目录（新建）

`demos/outer-wilds-cinematic-pptx/`

| 路径 | 用途 |
|------|------|
| `sources/game-extract/` | UnityPy 精选抽出的原纹理 |
| `sources/web-hq/` | 高清网图原料 + 简短来源备注 |
| `elements/` | 截取后的关键元素 |
| `plates/` | AI 打磨后的 16:9 分层底板 |
| `fx/` | 流星雨等序列帧 / 短循环视频 |
| `fonts/` | 衬字字体（本机已有可用字体或系统字体） |
| `out/` | 成品 `.pptx` |
| 构建脚本 | 组装页面、挂文案与动效 |

### 6.2 优先级

1. 游戏包精选抽取  
2. 不足 → 高清网络实机图原料  
3. 截取元素 → AI 打磨 → `plates/` / `fx/`  
4. 写入 PPT

### 6.3 动效优先级（流星及其他同理）

1. 短视频 / 序列帧循环（首选）  
2. 带真实拖尾的运动图像层  
3. 形状动画仅作不得已的辅助，且不得单独充当「华丽」

流星雨验收：多条斜向轨迹、长度与透明度变化、时间错峰、可见尾迹，观感为「划过天空」，而非色块闪烁。

## 7. PPT 结构原则（对齐芙莉莲工艺）

- 每页主视觉 = 打磨后的整页图和/或视频层  
- 大号半透明英文衬字 + 中文金句/剧情（嵌进画面，不是说明书列表）  
- 自动换页；章节门与高潮页可用更强转场，但不得用劣质闪烁凑数  
- 默认挂用户已购 OST **Main Title**（78.3 s，构建时复制到 gitignore 的 `media/`）；不把 mp3 提交进仓库；README 写明仅本机个人学习放映

## 9. 风险与诚实边界

- Unity 包体积极大：必须**精选**抽取，禁止无差别倾倒。  
- 网图质量参差：宁缺毋滥；低于清晰度门槛的不用。  
- AI 打磨可能改变局部细节：以「教学叙事可读 + 气质正确」为准，不追求像素级复刻某一官方宣传帧。  
- PowerPoint 对视频/序列帧有体积与兼容限制：单段 fx 控制时长与分辨率，避免文件过大无法打开。
