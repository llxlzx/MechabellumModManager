## 1. Requirements (English)

- Windows 10 / 11 **x64**
- Steam *Mechabellum*
- Prefer the **Setup** from [Releases](https://github.com/llxlzx/MechabellumModManager/releases/latest) (run as Administrator)

---

## 2. Install (recommended) (English)

1. Run `MechabellumModManager_Setup_v*.exe` as **Administrator**.  
2. Choose **where to install the manager**.  
3. Choose the **game folder** (must contain `Mechabellum.exe` and `GameAssembly.dll`; Steam path can be auto-detected).  
4. Components (recommended defaults):
   - **.NET 8 Desktop Runtime** 鈥?manager  
   - **.NET 6 Desktop Runtime** 鈥?common MelonLoader dependency  
   - **MelonLoader** 鈥?if not already installed in the game (skipped when present)  
5. Launch from the Start Menu when finished.

If the matching Runtime is already installed, Setup skips it.

Offline builds: place official Runtime / MelonLoader zips into `packaging/installer/redist/` before compiling Setup.

---

## 3. Daily use (English)

1. **Import** mods (DLL / Zip / folder) or **Import from game**.  
2. Select a **profile**, tick the mods to enable.  
3. **Apply profile** or **Apply and launch**.  
4. Optional: **Browse mods** 鈫?**Refresh catalog** 鈫?**Add to library**, then enable in a profile.

Data defaults to `%AppData%\MechabellumModManager\` (empty library; Setup does **not** ship third-party mods).

High-risk mods require confirmation. Use the status bar and sync log to verify deployment.

**Check for updates** tries the domestic mirror `latest.json` first (if configured), then GitHub Releases 鈥?**no** silent auto-install. On failure it copies domestic download notes instead of only opening GitHub.

Without a VPN: catalog and updates depend on the mirror being in sync. Clash / similar tools must enable **system proxy** or TUN; browser-only rules do not help the manager. A successful catalog fetch is cached locally; if both sources fail, import a Zip from the group files.

Settings 鈫?**Official / Beta** can keep two game folders (about two copies of disk space; Steam must quit). Run the setup wizard first.

## 4. MelonLoader (English)

Install MelonLoader **only via the Setup installer**. The manager no longer offers one-click Melon install.

If Loader is missing: re-run Setup and tick MelonLoader, or install manually per official docs into the game folder.

## 5. Community submit / report (English)

Submit, update, report, and feedback by email to **llxmod@foxmail.com** (standard subject prefixes). No Fork/PR required.

In the manager, **Submit / Report** copies the template or report body to the clipboard and opens webmail by UI language (QQ Mail for Chinese UI, otherwise Gmail). Paste and send. You can also email manually using the catalog repo templates.

Templates: [MechabellumMods README](https://github.com/llxlzx/MechabellumMods#鎶曠涓庝妇鎶?-submit--report) 路 [submit.html](https://github.com/llxlzx/MechabellumMods/blob/main/docs/submit.html)

The maintainer will review within a reasonable time; brief delays may occur due to daily life and personal schedule. Please do not resend the same request.
