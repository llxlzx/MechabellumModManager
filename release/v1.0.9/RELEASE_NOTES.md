## 中文
- 独占页面：本地库 / Mod 工坊 / 设置互斥全页，顶栏常驻
- UI：布局密度、工业风抛光；导航改为「已装 Mod」「Mod 工坊」；运行日志可展开/收起
- 跟随系统语言：按 Windows 显示语言解析（不再误跟应用当前语言）
- Melon：双服同步不再复制陈旧 Config.cfg；缺程序集时会失效并重新生成
- 安装器：五语 + 种子配置；.NET 静默安装；结束前不再二次启动管理器（避免重复完成感）
- 配置：ProgramData 安装种子；首启合并到日常用户 AppData
- 目录多选批量入库；应用方案仅脏可点；缺 Il2Cpp 程序集时询问是否生成

## English
- Exclusive pages: Installed / Workshop / Settings (top bar stays)
- UI: density + industrial polish; Installed / Workshop labels; expandable activity log
- Follow system language: uses Windows display language (not the app’s overwritten UI culture)
- Melon: dual-store sync skips stale Config.cfg; invalidates and regenerates when assemblies missing
- Installer: 5 languages + config seeding; quiet .NET install; no manager launch before Finished page
- Config: ProgramData install-defaults; merge into daily-user AppData on first launch
- Catalog multi-select batch add; Apply only when dirty; ask before Il2Cpp assembly generation
