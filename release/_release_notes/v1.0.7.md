## 中文
- 正式服 / 测试服双目录切换；测试分支默认 `public_test`
- 切服加固：等待 steamwebhelper、退出后冷却、已对齐则不强制重启 Steam；下载中勿切服
- ACF 快照：当 BytesToDownload 等于 BytesDownloaded 时视为已定居，降低切服后重复下载
- 双服 MelonLoader 框架同步（不跨服复制 Il2CppAssemblies）
- 安装器原生写入管理器配置，降低 PowerShell 启动失败影响
- 文案与对话框校准

## English
- Official / Beta dual-folder switch; default Steam beta `public_test`
- Safer switch: wait for steamwebhelper, post-exit cooldown, skip restart when already aligned; do not switch mid-download
- ACF snapshots: treat BytesToDownload == BytesDownloaded as settled to reduce re-downloads after switching
- MelonLoader dual-store framework sync (does not copy Il2CppAssemblies across stores)
- Installer writes manager config natively to reduce PowerShell launch failures
- Copy and dialog calibration
