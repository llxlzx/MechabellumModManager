## 中文
- Mod 浏览：预览图、更完整的条目信息，加入本地库
- 本地库：点选查看介绍、署名与更新信息
- 导入增强：文件夹/Zip 多 DLL 拆分；可从游戏 Mods/Plugins 扫描导入
- 修复：损坏配置崩溃、目录空路径等稳定性问题

## English
- Catalog: previews, richer metadata, add-to-library
- Library: select a mod to view summary, credits, and update info
- Import: split multiple Melon DLLs from folder/Zip; scan game Mods/Plugins
- Fixes: crash on corrupt config, empty catalog paths, and related stability issues
