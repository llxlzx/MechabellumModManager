# DEPRECATED — Mechabellum Mod Relay

**Do not deploy this Worker.**

Mod submissions and reports now go through the catalog GitHub repository directly:

- **Submit mods:** Fork + Pull Request (see the MechabellumMods README contribute guide)
- **Report mods:** Open a GitHub Issue with the `report` label (the desktop manager opens the pre-filled Issues URL)

This folder is retained only as historical reference. The desktop app no longer uses a Cloudflare relay (`RelayClient` / `relayBaseUrl` removed).
