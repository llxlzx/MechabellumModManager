# 这个文件夹里都是什么

程序文件夹用英文，是为了让编译和测试还能找到它们。不要改这些名字。

| 文件夹 | 意思 |
|--------|------|
| `src` | 管理器源码 |
| `tests` | 自动测试 |
| `docs` | 给人看的中文说明，从 `docs\读我.md` 进 |
| `packaging` | 打安装包用的脚本和离线运行库 |
| `services` | 作者上传用的网上小服务 |
| `mods` | 配套的黑匣子 Mod |
| `tools` | 同步镜像、导入收件箱、发版的脚本 |
| `release` | 只留更新指针 `latest.json`，旧版本安装包已删 |
| `dist` | 只留当前安装包 `MechabellumModManager_Setup_v1.3.17.exe` |
| `.vscode` | 在 Cursor 里按哪个键编译 |
